# 🎮 Hangman<br><br>
---

Build_something is a Hangman game I made in Python 🐍 .<br><br>

The game randomly chooses a word from Word_list.py and gives you the usual Hangman challenge of guessing the word before you run out of attempts. The Hangman drawings used in the game are stored in arts.py 🎨.<br><br>

## 📂 Files<br><br> 
🐍 Build_something.py — Contains the main game and its logic.<br>
📖 Word_list.py — Contains the list of words used in the game.<br>
🎨 arts.py — Contains the ASCII art for the Hangman stages.<br><br>

## 🎯 How to Play<br><br>
Run Build_something.py.<br>
A random word will be selected.<br>
Guess letters one at a time.<br>
Correct guesses reveal the letters in the word.<br>
Wrong guesses add another part to the Hangman.<br>
Guess the word before you run out of attempts 💀.<br><br><br>



## 🛠️ Requirements<br><br>
Python 3.x 🐍<br><br>

▶️ Made entirely by me with the minimal help of AI <br>
