🎮 Hangman

Build_something is a Hangman game I made in Python 🐍 for the ACE Programming Extreme Task.

The game randomly chooses a word from Word_list.py and gives you the usual Hangman challenge of guessing the word before you run out of attempts. The Hangman drawings used in the game are stored in arts.py 🎨.

📂 Files
🐍 Build_something.py — Contains the main game and its logic.
📖 Word_list.py — Contains the list of words used in the game.
🎨 arts.py — Contains the ASCII art for the Hangman stages.
🎯 How to Play
Run Build_something.py.
A random word will be selected.
Guess letters one at a time.
Correct guesses reveal the letters in the word.
Wrong guesses add another part to the Hangman.
Guess the word before you run out of attempts 💀.
🛠️ Requirements
Python 3.x 🐍
A terminal or Python IDE
▶️ Running the Game

Run the following command:

python Build_something.py

Have fun and good luck guessing the words! 🎮
